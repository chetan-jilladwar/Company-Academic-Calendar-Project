# 📅 Company Academic Calendar

A responsive and modern web application to manage and display company holidays, employee events, and upcoming activities — all in one interactive calendar view.

---

## 🚀 Features

- 📆 Dynamic and interactive calendar view  
- 🎉 Add and manage company holidays or custom events  
- 👥 Add employee details with leave tracking  
- 🔔 Leave notifications and upcoming event alerts  
- 🗓 Separate sections for Add Employee, Add Holiday, Upcoming Events  
- 📱 Fully mobile responsive with smooth scrolling design  

---

## 🧰 Tech Stack

*Frontend:* HTML, CSS, JavaScript  
*Database:* Google Sheets (for event storage)  
*Icons:* FontAwesome / Material Icons  

##  Run the app

- Open index.html directly in your browser
